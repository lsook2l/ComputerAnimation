## 프로젝트 목록

### RockPaperScissors
가위바위보 게임입니다.

플레이어가 가위, 바위, 보 버튼 중 하나를 선택하면 컴퓨터가 랜덤으로 선택하고, 두 선택 결과를 비교하여 승패를 판정합니다. 플레이어 또는 컴퓨터가 먼저 5점에 도달하면 최종 결과 패널이 표시되며 게임이 종료됩니다.

주요 기능:
- 가위, 바위, 보 버튼 선택
- 컴퓨터 랜덤 선택
- 플레이어와 컴퓨터 선택 이미지 표시
- 승패 판정 및 점수 증가
- 먼저 5점 달성 시 최종 승리 처리
- 재시작, 초기화, 종료 기능

---

### CherryDash
체리를 먹고 장애물과 플랫폼을 피하는 러닝 게임입니다.

플레이어는 제자리에서 달리는 캐릭터를 점프 또는 슬라이드하여 배치된 체리를 획득하면서 장애물과 플랫폼을 피해야 합니다.

주요 기능:
- 캐릭터 점프 및 슬라이드
- 체리 아이템 수집
- 장애물 및 플랫폼 회피
- 러닝 게임 방식의 진행 구조
- Unity 빌드 실행 파일 포함

---

### WASD Escape
랜덤 키 배정을 기반으로 한 Unity 2D 협동 장애물 회피 게임입니다.

Player1은 WASD 중 2개, Player2는 방향키 중 2개를 랜덤으로 배정받아 하나의 드래곤 캐릭터를 함께 조작합니다. 한 번 방향키를 누르면 캐릭터가 해당 방향으로 계속 이동하며, 두 플레이어가 협력하여 맵에 배치된 딸기 보석 아이템을 모두 수집해야 합니다.

딸기 보석 4개를 모두 수집하면 클리어 포털이 활성화되며, 포털에 도달하면 게임을 클리어할 수 있습니다. 벽이나 파티클 기반 풍차형 장애물에 닿으면 현재 키 배정은 유지한 채 시작 지점으로 리셋됩니다.

주요 기능:
- 플레이어 이름 입력 및 랜덤 키 배정
- Player1: WASD 중 2개 랜덤 배정
- Player2: 방향키 중 2개 랜덤 배정
- 한 번 키를 누르면 해당 방향으로 계속 이동하는 조작 방식
- 딸기 보석 수집 및 개수 카운트 UI
- 딸기 4개 수집 시 클리어 포털 활성화
- 파티클 효과를 활용한 풍차형 장애물
- 벽 또는 장애물 충돌 시 리셋
- ESC 메뉴, 계속하기 3초 카운트다운, 재시작, 종료 기능
- 배경음악 및 효과음 구현
