# WASD Escape

> Computer Animation Term Project  
> Unity 2D 협동 조작 게임

## 프로젝트 개요

**WASD Escape**는 Unity 2D 환경에서 제작한 컴퓨터애니메이션 텀프로젝트 게임입니다.  
플레이어는 드래곤 캐릭터를 조작하여 맵에 배치된 딸기 보석 아이템 4개를 모두 수집하고, 이후 활성화되는 클리어 포털에 도달해야 합니다.

일반적인 방향키 이동 게임과 달리, 게임 시작 시 Player1과 Player2에게 이동 키가 랜덤으로 나뉘어 배정됩니다.  
Player1은 `W`, `A`, `S`, `D` 중 2개를, Player2는 방향키 중 2개를 배정받아 함께 캐릭터를 조작합니다.

## 게임 규칙

1. 게임 시작 화면에서 Player1, Player2의 이름을 입력합니다.
2. 키 부여 버튼을 누르면 각 플레이어에게 이동 키가 랜덤으로 배정됩니다.
3. 한 번 방향키를 누르면 드래곤 캐릭터가 해당 방향으로 계속 이동합니다.
4. 맵에 배치된 딸기 보석 아이템 4개를 모두 수집해야 클리어 포털이 열립니다.
5. 벽 또는 장애물에 닿으면 현재 키 배정은 유지한 채 시작 지점으로 리셋됩니다.
6. 클리어 포털에 도달하면 `STAGE CLEAR` 화면이 표시됩니다.

## 주요 기능

### 1. 타일맵 기반 맵 구성

맵은 Unity Tilemap을 사용하여 구성했습니다.

| 오브젝트 | 역할 |
|---|---|
| `GroundTilemap` | 캐릭터가 이동하는 바닥 |
| `WallTilemap_1` | 닿으면 리셋되는 벽 / 위험 구역 |
| `WallTilemap_2` | 충돌 판정이 없는 디자인용 벽 |
| 배경 이미지 | 맵 뒤쪽 배경 표현 |

### 2. 랜덤 키 배정 시스템

게임 시작 시 Player1과 Player2에게 키가 랜덤으로 배정됩니다.

| 플레이어 | 배정 키 |
|---|---|
| Player1 | WASD 중 2개 |
| Player2 | 방향키 중 2개 |

예시:

```text
Player1: W, A
Player2: ↓, →
```

### 3. 딸기 보석 수집 시스템

- 총 4개의 딸기 보석 아이템 배치
- 딸기 획득 시 아이템 삭제
- 딸기 획득 이펙트 및 사운드 재생
- UI에 딸기 아이콘과 함께 수집 개수 표시
- 4개 모두 수집 시 클리어 포털 활성화

### 4. 클리어 포털 시스템

딸기 보석 4개를 모두 수집하면 클리어 포털이 활성화됩니다.  
활성화된 포털에 닿으면 클리어 패널이 표시됩니다.

### 5. 파티클 기반 풍차형 장애물

파티클 효과가 포함된 장애물 프리팹을 제작하고, `WindmillObstacleGenerator` 스크립트를 통해 중심 좌표 기준으로 자동 배치되도록 구현했습니다.

- 4개의 날개 생성
- 각 날개마다 5개의 장애물 생성
- 총 20개의 장애물 자동 생성
- 장애물 개수, 간격, 회전 속도, 회전 방향 조절 가능

### 6. ESC 메뉴 및 카운트다운

게임 중 `ESC` 키를 누르면 메뉴가 표시됩니다.

- 계속하기
- 재시작
- 종료

계속하기 버튼을 누르면 바로 게임이 재개되지 않고 `3, 2, 1, START!` 카운트다운 후 게임이 재개됩니다.

### 7. 사운드 시스템

`AudioManager`를 통해 배경음악과 효과음을 통합 관리합니다.

| 사운드 | 발생 시점 |
|---|---|
| 배경음악 | 게임 진행 중 반복 재생 |
| 딸기 획득 사운드 | 딸기 보석 획득 시 |
| 충돌 사운드 | 벽 또는 장애물 충돌 시 |
| 클리어 사운드 | 클리어 포털 도착 시 |

## 프로젝트 실행 방법

1. Unity Hub를 실행합니다.
2. `WASD Escape` 프로젝트 폴더를 엽니다.
3. `Assets/Scenes` 폴더에서 메인 씬을 엽니다.
4. Unity 상단의 Play 버튼을 눌러 실행합니다.

## 트러블슈팅 요약

개발 과정에서 다음 문제를 해결했습니다.

- Tilemap에 Box Collider를 적용해 전체 영역이 충돌 판정되는 문제
- 파티클 입자 자체에 Collider2D가 적용되지 않는 문제
- Material 또는 Texture 삭제로 인해 오브젝트가 핫핑크/네모로 표시되는 문제
- Main Camera가 Player 자식으로 들어가 있어 충돌 시 카메라가 꺼지는 문제
- ESC 메뉴, 클리어 패널에 여러 스크립트에 재시작, 종료 기능 중복
